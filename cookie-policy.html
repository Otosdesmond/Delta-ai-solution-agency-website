Cookie Policy

Last updated: 18 September 2026

This page explains how Delta AI Solutions Agency uses cookies on this website (https://deltaai.solutions).

Current status

As of the date above, this website does not set any tracking, advertising, or analytics cookies. It does not use Google Analytics, Meta Pixel, or any similar third-party tracking script. Because we don't use non-essential cookies, we don't currently show a cookie consent banner, there is nothing on this site yet that requires your consent.

If this changes

If we later add analytics or any other tool that sets cookies, we will update this page to describe exactly what is set and why, and we will add a consent option before any non-essential cookie is placed, in line with applicable Nigerian data protection requirements.

Browser controls

You can control or clear cookies at any time through your browser's settings, regardless of what a specific website does.

Demo assistants

The linked Deltie demo applications are separate from this website and may use minimal local storage, for example to keep track of your conversation within that page. Contact us for details on a specific demo.
